# Tiyin — On-Device AI Financial Assistant for Uzbekistan

Modern, responsive landing page for **Tiyin**, a local, on-device AI financial assistant built for residents across Uzbekistan to manage everyday payments, recurring bills, and money transfers privately and effortlessly across **Click**, **Payme**, **Uzum**, **Monix**, and **Tez**.

## Tech Stack
- **React 19** + **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Vite 8**
- **Lucide React** (icons)

## Local Development

```bash
npm install
npm run dev
```

## Type Check, Tests & Production Build

```bash
npm run lint
npm run test
npm run build
```

## Deployment on Vercel
Configured out-of-the-box via [`vercel.json`](./vercel.json):
- **Framework Preset**: `Vite`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
